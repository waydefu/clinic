**答案：技術審查人與資安審查人皆為業主（診所負責人）與 wayde。**
（2026-08-23 業主與 wayde 口頭指定，wayde 代述。）

⚠️ **必須一併記錄的剩餘風險：實作者與審查人為同一人。**

wayde 同時是本專案的實作者與（其中一位）審查人，技術審查與資安審查也未由兩位
獨立人員分擔。這代表**沒有第二雙眼睛**：實作上的盲點不會在審查階段被攔下。

以診所規模而言這通常無法避免，正規做法不是當作沒發生，而是明確登記為**已知並接受
的剩餘風險**，並以補償控制降低影響：

- 所有變更走 PR 與必要檢查，不得直接推 `main`；
- `enforce_admins=false` 的 bypass 使用前仍須自行跑完整 gate，且每次使用要留紀錄；
- 高風險變更（權限、Rules、稽核、outbox、部署）盡量拆小、附反向測試。

此風險須由具名者簽收，助理不代簽。

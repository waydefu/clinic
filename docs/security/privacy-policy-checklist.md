# 隱私政策與個資上線檢核

此文件是產品與法務的檢核表，不替代正式法律意見。

## 病患端必備內容

- [ ] 診所的正確名稱、地址、電話與個資聯絡窗口。
- [ ] 蒐集目的：預約、取消/改期、必要聯繫、已指派個管的服務追蹤與資訊安全。
- [ ] 依 D-001～D-003 核准逐欄列出正式資料類別、必要性、法律依據與保存期限，不得沿用原型預設。現行合成預覽的候選清單是姓名、電話、生日（月／日必填、年份選填）、身分證／居留證或護照、健保卡攜帶意向、預約服務／時段、門診／來源標籤、條件式介紹人姓名與短備註；不收 Email、LineID 或性別，也不得把這份候選清單視為正式核准。
- [ ] 另行審查可能涉及健康／醫療資訊的門診需求標籤與自由文字備註，以及涉及第三人的介紹人姓名；無法證明必要性與合法依據時移除。
- [ ] 利用期間、地區、對象、方式與受託處理的供應商/類別，應與實際部署及合約一致。
- [ ] 當事人的查詢、閱覽、複製、更正、停止蒐集/處理/利用、刪除等權利與申請方式。
- [ ] 不提供必要資料的具體後果，例如無法完成線上預約或驗證取消。
- [ ] 生效日、版本號、更新紀錄及資安事件聯絡方式。

## 同意與紀錄

- [ ] 送出前顯示短摘要與完整政策連結；記錄版本、內容雜湊、時間、語言與通路。
- [ ] 預約必要告知的閱覽確認，不與行銷同意混用。
- [ ] 行銷/回診促銷/再行銷使用獨立、未預勾、可撤回的選項與獨立 audit event。
- [ ] 個管僅能存取已指派案件；禁止匯出患者聯絡資料與私下保存。
- [ ] 職務異動、離職或帳號風險時，立即停權、轉派案件並稽核。

## 法務審核提示

個資法第 8 條對直接蒐集個資的告知事項有具體要求；醫療與健康檢查資料的定義及委外監督也應另行確認。最終文字與實際供應商資料處理範圍必須由診所法務/個資窗口核准。

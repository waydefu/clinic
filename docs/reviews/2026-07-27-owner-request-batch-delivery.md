## 這次做的過程中發現並修掉的真缺陷

不是需求，是實作時撞出來的：

1. **患者頁對回訪者會整個失效**（批次 2）。`renderBookingTypeButtons()` 在診所
   資料到達前會先跑一次，而新的「已確認回診就停用初診」判斷會去讀
   `state.followUps`——對本機已記著 patientId 的回訪患者，那是一個會炸掉整個
   模組初始化的存取。症狀是「畫面看起來畫好了，但所有按鈕都沒有反應」。
2. **HTML 註解被原封不動送給每一位訪客**（F-1）。建置只壓 CSS 與 JS。修掉之後
   患者頁的 document 由 8.9 KiB 降到 6.6 KiB、工作臺由 11.2 降到 9.2。
3. **`check:tokens` 只涵蓋一半的樣式表**（F-2），納入後當場抓到 11 筆違規。
4. **JS 注入的輸入欄位完全不受「新增欄位」把關**（F-3）。
5. **對外頁面清單在五處各抄一份**（F-4），漏掉其中一份不會有任何錯誤。
6. **翻譯守衛只擋代碼、不擋欄位**（F-6），批次 3 的兩個新欄位就這樣溜過去。

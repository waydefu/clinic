# 官網與預約頁綜合評分（v2 標準）— 2026-10-25

依 [公開網站綜合評分標準 v2](../design/site-audit-rubric.md) 第一次評分。受評的是
[#302](https://github.com/waydefu/clinic/pull/302) 的程式（官網改進候選），不是 main，也不是 live。
這是稽核紀錄，不是 gate、不是上線核准，也不是醫療或法律審閱。

## 1. 總分

網站本身的進步：每頁有獨立標題與描述、axe 掃描 0 違規、預約頁和官網的風格已經一致。

## 4. 不足清單（依嚴重度）

1. **官網醫療廣告用語（F 上限、也是上線風險）**
   - 「自體肋隆鼻權威」：`clinic-content.js:242`。
   - 療效句寫進副標，也寫進 meta 與 og 描述：「改善長期鼻塞，讓日常呼吸與睡眠更順暢」（`:389`）、「重新找回通暢呼吸」（`:493`）。
   - 比較表列「廣達雷射」（`:464`），疑似具名廠牌，要業主確認。
   - 改掉這幾處就解除上限。再補執照與證書字號、科別、官網的健保特約字樣，F 最多可回到 7～8 分。
2. **官網原始 HTML 沒有正文**（A3、B5）。
   - 路由頁已經在建置時產生，可以把該頁的 h1、導言與主圖也寫進 HTML。
   - 預估 A 加 4、B5 加 2，首頁 LCP 也會跟著變快。
3. **載入慢**（B1、B3）。
   - 官網首頁節流 LCP 4.3 秒，預約頁 4.5 秒，預約頁 TBT 1.6 秒。
   - 預約頁要等 32 個模組載完才顯示畫面。
4. **官網焦點框對比不足**（C2）。
   - `#d49b45` 改用預約頁已在用的 `--brand-focus-ring`（`#7a5400`），並補 `forced-colors`。
   - 改動很小，可加 3 分。
5. **分享與正規網址**（A1、A2）。
   - 官網各路由缺 canonical 與 og:image，首頁缺 og:title。
6. **公開頁 CSP 過寬**（G2）。
   - 官網與預約頁都允許用不到的 Firebase Auth 與 `apis.google.com`。
7. **預約頁細節**
   - JSON-LD 的「醫學美容」。
   - 手機版頁首沒有「回官網」。
   - 第 3 步備註欄沒有「勿填病情細節」提醒。
   - 個資告知仍是草稿。
   - 單一看診項目仍要點一下。
8. **軟 404 回 HTTP 200**（評分表沒有這一項，另列）。
   - `/clinic/not-a-page` 回 200，原始 HTML 的標題是首頁標題。
   - 搜尋引擎可能把不存在的網址當成重複頁收錄。
9. **大檔**（H3）：`clinic-site.js` 1,649 行、`patient-app.js` 1,457 行。

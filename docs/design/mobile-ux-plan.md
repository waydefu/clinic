# 行動版 UX 規劃

**狀態：** plan-only 設計規劃。

**撰寫日期：** 2026-08-04

[介面規則書](ui-ux-rules.md) 是 binding 規則，本文件不得牴觸它。既有的行動版修正
成果記錄在 [roadmap](../roadmap.md) 的 2026-07-26／2026-07-29 條目，本文件**不重做**
那些已完成的項目。

---

## 1. 現況

行動版並非未經處理。已完成並由測試守住的部分：

- `mobile-layout.spec.ts` 以瀏覽器幾何量測守住 320／375px 重排、viewport 邊界與 44px
  操作高度（12 項）。
- 320～480px 的分頁按鈕、篩選列、處置卡、批次動作、排班起訖時間都已個別修正。
- 200% 文字縮放重排已驗證。
- 通知面板已固定於手機 viewport 安全內距。

**尚未處理的是結構性問題**，不是個別破版：導覽仍是桌面式 header、資料表在窄版靠
重排而非改成卡片、沒有全螢幕 Sheet 這個層級。

---

## 2. 導覽

桌面的左側導覽在手機改為**抽屜（drawer）**：

- 由 header 左側的選單鈕開啟，覆蓋式，帶遮罩。
- 開啟時焦點移入抽屜並鎖在其中；`Escape` 關閉並把焦點還給觸發鈕。
- 關閉時遮罩不可殘留攔截點擊——這是常見缺陷，須有測試。

診所官網的行動選單已有可開啟／`Escape` 關閉的實作與測試
（[`clinic-site.spec.ts`](../../tests/e2e/clinic-site.spec.ts)），工作臺抽屜應沿用
同一套焦點行為，不另發明。

---

## 3. 日程

**預設為當日清單**，不是七欄週曆。七欄在 390px 上每欄只有約 50px，事件文字必然被裁切
（2026-07-25 已因此修過一次週曆文字裁切）。

- 日期以左右滑動或上方日期帶切換。
- 週檢視仍可手動切換，但不作為預設。
- 事件卡顯示：時間、病患姓名、類型色條、狀態 chip。

---

## 4. 資料表卡片化

窄版不重排資料表，改為卡片。轉換規則：

| 桌面表格 | 手機卡片 |
| --- | --- |
| 主要識別欄（姓名） | 卡片標題 |
| 時間／日期 | 標題下方次要行 |
| 狀態 | 右上角 chip（含文字，不只顏色） |
| 其餘欄位 | 標籤：值 逐行 |
| 列操作 | 卡片底部，主要動作全寬、兩個次要動作並排 |

最後一列的版型已在 2026-07-26 的處置卡定案，卡片化沿用同一規則，不另立一套。

---

## 5. Sheet、Dialog 與 Drawer

| 元件 | 桌面 | 手機 |
| --- | --- | --- |
| 詳細資料 | 右側 Drawer | **全螢幕 Sheet** |
| 確認操作 | Dialog（置中） | Dialog（置中，寬度 100%－2×間距） |
| 選單 | Popover | 底部 Sheet |

全螢幕 Sheet 必須有明確的關閉鈕，不只依賴下滑手勢——手勢在輔助技術下不可靠。
既有的自製確認彈窗（禁用 `window.confirm`）繼續沿用。

---

## 6. 硬性版面要求

1. **不可出現水平 overflow**，320px 以上任何頁面皆然。
2. **消除異常底部留白**——目前部分頁面在短內容時有多餘空白，需查明來源（多半是
   固定高度容器或 `min-height: 100vh` 與 header 疊加）。
3. 頂部工具列與通知按鈕重新配置，避免與抽屜選單鈕擠在同側。
4. 所有主要觸控區 ≥ 44×44px（既有規則，已由測試守住）。
5. 安全區域內距（`env(safe-area-inset-*)`）在瀏海與圓角螢幕上必須生效。

---

## 7. Viewport 驗收矩陣

| 尺寸 | 代表裝置 | 現況 |
| --- | --- | --- |
| 320 × 568 | iPhone SE 1 / 最窄下限 | 已測 |
| 360 × 800 | Android 主流 | **新增** |
| 390 × 844 | iPhone 14 | 已測（診所官網） |
| 412 × 915 | Pixel | **新增** |
| 430 × 932 | iPhone Pro Max | **新增** |
| 768 × 1024 | iPad 直式 | **新增** |

六個尺寸全部納入 `e2e-mobile` 分組。768×1024 是分界點：它應該走桌面版面還是平板
版面，需要在實作時明確決定並寫進本文件，不可讓它落在兩套規則的縫隙裡。

---

## 8. 驗收條件

1. 六個 viewport 全部無水平捲動。
2. 抽屜導覽可開啟、`Escape` 關閉、焦點正確回到觸發鈕、遮罩不殘留。
3. 日程在手機預設為當日清單。
4. 資料表在窄版呈現為卡片，不是壓縮的表格。
5. 全螢幕 Sheet 有可見的關閉鈕且焦點被鎖住。
6. 200% 文字縮放下不破版（既有要求）。
7. `e2e-mobile` 與 `e2e-accessibility` 兩組全綠。

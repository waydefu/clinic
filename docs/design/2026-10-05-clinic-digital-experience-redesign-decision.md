# 一森渼診所 Digital Experience 重設計決策（Clinic Digital Experience Redesign Decision）

**日期：** 2026-10-05　**性質：** 設計決策提案，**等待負責人批准**。
本文不核准任何部署、apply、真實資料、醫療文案或 D-series 事項；也不是施工完成紀錄。
**狀態：** 方向已獲負責人批准（2026-10-05），附 Visual Proof gate；
原型與後續負責人決定見 [Visual Proof Sprint 交接](2026-10-05-visual-proof-sprint-handoff.md)
（其 §5 列出與本文不同、以負責人最新指示為準的項目，例如首屏改為診所實景輪播、不放醫師照）。

## 0. 執行摘要（Executive decision）

1. **要重構，但只重構「外觀與資訊節奏」，不重構技術。** 保留原生 HTML／CSS／ES Modules、現有建置、
   素材管線、預約流程與所有檢查閘門；不引入框架、動畫套件或字型檔。
2. **選定方向：「霧林呼吸」（Misty Forest Breath）。** 以舊官網花錢做的霧林照片、白色醫學線稿、
   呼吸弧線與星點為品牌核心，用編輯式排版把它們重新組合；不是 botanical 插畫、不是飯店奢華、不是醫美金黑。
3. **舊素材是核心，不是包袱。** 63 張中約 40 張值得留下（含你指定要留的四個特色圖示、七張線稿、
   鼻中隔分類圖），其中「霧林照片家族」與「白色線稿家族」會成為整站的兩個記憶點。
4. **官網與 `/booking` 共用同一套 token 與頁首元件**；預約頁只在頁首下方放一條「霧林地平線」氛圍帶，
   表單放在實心白卡上，輸入框後面永遠沒有圖。
5. **最大風險有三個：** 舊素材多數把文字烙在圖裡（違反介面規則書 R-26，必須拆成 HTML）；
   舊文案有療效與比較用語（醫療廣告風險，需診所審）；舊官網 URL 有搜尋權重，換站必須做 301 對照。
6. **最值得投資的地方：** 把七張白色線稿與五個鼻中隔示意圖**向量化成 SVG**（小錢、一次性，換來清晰、極小、
   可換色、深色模式可用）。不需要新拍攝：現有 5 張診所環境照片解析度高達 6000px，只是從沒被好好用過。

### 3.2 哪些舊素材值得成為新網站的「核心」

1. **霧林照片家族（#1、#2、#4、#6）**：成為簽名 1「霧林地平線」，官網與預約頁共用。
2. **白色線稿家族（#18～#21）＋軌道星點母題**：成為簽名 2「呼吸弧線」與全站療程圖像語言。
3. **四個特色圖示（#23）與鼻中隔五型（#24）**：照你的要求保留，前者放首頁信任區、後者放鼻中隔頁。
4. **診所實景照片（#12～#16）**：取代現在「只有插畫、看不到診所長什麼樣」的缺口。
5. **兩位醫師去背照（#35、#36）**：疊在霧林地平線上，做出「人站在森林前」的分層構圖。

### 3.3 素材遷移計畫（本輪不執行）

1. **先跟設計師要原始檔**（Canva／AI／PSD），尤其是線稿與鼻中隔圖；拿得到就以原始檔為母檔，網站版只當備援。
2. 母檔存業主 Google Drive；repo 只放出貨用 WebP／SVG，延續 `clinic-assets.manifest.json` 記錄來源網址、sha256、授權依據。
3. 擴充 `scripts/build-clinic-assets.mjs` 的輸出規格（hero、內頁橫幅、環境照、線稿），**每張烙字圖都要宣告裁切框**
   （R-26 與 `MAX_BLIND_DISCARD` 已要求）；不加 Sharp 等新相依。
4. 線稿與鼻中隔五型：先用裁切 WebP 上線；向量化 SVG 完成後替換（見 §15）。
5. 霧林、絲光等照片疑似設計師使用的圖庫素材：用在診所自己的網站通常在授權內，但請設計師確認一句。

## 4. 現況使用者旅程與判決

### 4.1 現行旅程（repo `/clinic` → `/booking`）

```
進入首頁 → 看到院長與標語（首屏清楚）→ 症狀導引（選一項）→ 四張療程卡 → 四步評估流程
→ 測鼾聲 App → 醫師 → 門診與交通 → FAQ → 預約 CTA → /booking
→ ①類型與項目 → ②日期時段 → ③基本資料 → 成功
```

### 4.2 摩擦與問題

| 問題 | 證據 |
| --- | --- |
| 首頁太長、節奏單調 | 390 寬共 11,356px（約 13.5 個螢幕）；1440 寬 7,043px；九個區塊幾乎都是同一種白底卡片或淡綠底 |

### 4.3 主要區塊判決

| 區塊 | 判決 | 理由 |

## 5. Art direction：三個方向與選擇

| 方向 | 做法 | 優點 | 不選的原因 |
| --- | --- | --- | --- |
| A. Botanical Clinical Editorial（你提的） | 紙感底、植物插畫、編輯式襯線 | 高級、安靜 | 一森渼**沒有植物插畫**，要做就得新請插畫師；而且 botanical 容易滑向通用 wellness 模板 |
| B. 診所實景（深綠皮革＋大理石＋古銅） | 以環境照為主視覺，深色調 | 最真實 | 照片只有 5 張；深綠＋古銅很容易變成你禁止的「醫美金黑模板」；鼻功能醫療的語氣應更明亮 |
| **C. 霧林呼吸（Misty Forest Breath）** | 霧林照片做地平線、白色線稿做圖像語言、軌道線做呼吸節奏、編輯式排版；環境照做信任證據 | **全部來自既有付費素材**、成本最低、最像一森渼 | — |

**決定：C。** 吸收 A 的編輯式排版紀律，B 的環境照只當「證據」用，不當主視覺。

## 6. 設計方向規格

- **名稱：** 霧林呼吸（Misty Forest Breath）
- **視覺主張：** 「先把呼吸看清楚」——霧散開、線條變清楚，就是從症狀走到原因的過程。
- **情緒：** 清楚、安靜、可信、不催促；像在晨霧森林裡深呼吸，而不是走進精品店。
- **簽名 1：霧林地平線。** 樹線永遠在畫面底部，往上淡入晨霧；出現在首頁主視覺、內頁頁首、預約頁頂端、結尾 CTA。
  技術上是一張 4～8 KiB 的 WebP 加 CSS `mask-image` 漸層。
- **簽名 2：呼吸弧線。** 舊衛教圖的白色橢圓軌道＋八角星點，用 inline SVG 重畫（0 張點陣圖），
  穿過大標題或線稿背後；首屏只畫一次、不循環。

### 6.1 色盤（取自官網與舊素材的實測色）

| 名稱 | Hex | 用途 | 對比（實算） |
| --- | --- | --- | --- |
| 森林綠 | `#184F40` | 主要按鈕、連結、標題（沿用現行 token） | 白底 9.41；晨霧底 7.80 |
| 墨綠 | `#182E27` | 內文、深色區塊與頁尾底（沿用現行 ink） | 晨霧底 11.93；白字 14.39 |
| 晨霧 | `#E4ECE3` | 行銷頁主底色（取自霧林圖左側） | — |
| 宣紙灰綠 | `#E5E5D5` | 插畫襯底；**與舊衛教圖底色一致，裁切的插畫可以無縫融進頁面** | — |
| 鼠尾草 | `#81A182` | 弧線、分隔線、線稿描邊等純裝飾 | 白底 2.86 → **不可承載文字或狀態** |

### 6.2 字體角色

- **維持 0 KiB 字型預算**（2026-07-27 負責人決定）：標題用系統宋體（`--font-serif-tc`），內文與介面用系統黑體。
- 已知限制：Windows 沒有 Noto Serif TC 時會退到細明體，大標題質感明顯較差。
  **選配投資（需負責人另行決定）：** 只為首頁與內頁大標題子集化一套宋體（約 40～80 字，估 15～30 KiB）。
- 數字、門診時間用黑體 `tabular-nums`；不使用等寬字當英文小標。

### 6.3 圖像處理

- 霧林照片：只當地平線或背景，永遠加淡入遮罩，不放在輸入框或內文後面。
- 線稿：白色線稿放在 `#184F40`／`#182E27` 深色面上，或改為森林綠描邊放在淺底上；SVG 化後同一檔兩用。
- 舊衛教插畫：一律裁掉烙在圖上的文字，襯在宣紙灰綠 `#E5E5D5` 上，讓圖邊消失。
- 環境照：16:10 或 4:5 裁切，柔和有機遮罩（單一形狀，非每張不同），不加濾鏡。
- 醫師：去背照疊在地平線前，頭部不裁切；姓名、職稱、專長全為 HTML。

### 6.4 版面節奏

一個區塊只做一件事，以「安靜 → 互動 → 編輯 → 結構 → 人 → 實用 → 轉換」的順序交替；
白卡只用在需要邊界的互動元件（預約、FAQ），不再整頁都是卡片。

### 6.5 AI 套路自我檢查

| 禁止項 | 本方案 | 說明 |
| --- | --- | --- |
| 暖米白＋赤陶 | 不用 | 底色來自霧林與舊衛教圖 |
| 紫色漸層／到處發光 | 不用 | 光弧改成一處、低透明度的 CSS 漸層；先前本機預覽的發光已取消 |
| 到處毛玻璃 | 不用 | 唯一可能是捲動後的頁首半透明，可直接改實色 |
| 每區都是卡片／pill | 不用 | 療程改交錯列表；pill 只留症狀選擇（它們確實是按鈕） |
| 超大圓角 | 不用 | 沿用 8／12／16px |
| 每區 01／02／03 | 只在評估流程使用 | 那是真的有先後順序的步驟 |
| 等寬英文小標 | 移除 | 改為中文短標或不放 |
| 單字斜體換色 | 不用 | — |
| 每張卡 hover 上浮、全部 fade-up | 移除 | 見 §10 |
| 圖示湯 | 不用 | 只用舊官網既有線稿與四個特色圖示 |
| 金色黑底 | 不用 | 芥黃只出現在醫學示意的重點線 |
| **有意保留**：樹線大圖 | 使用 | 不是裝飾漸層，而是業主付費素材與品牌記憶點 |

| M2 | 呼吸弧線描繪 | 主視覺與原因先行區第一次出現 | 1200ms／ease-in-out，只畫一次 | 直接顯示完整線條 | SVG stroke-dashoffset，無點陣圖 |
| M3 | 症狀選擇與推薦療程標示 | 點選 | 150～200ms 色彩／外框 | 立即切換 | 只動 color／outline |
| M4 | 預約步驟切換 | 下一步／上一步 | 150ms opacity；焦點移到新步驟標題 | 立即切換 | 無位移，不影響 CLS |
| 保留 | 頁首捲動收合 | 捲過哨兵 | 既有 | 既有 | 既有 |

**移除：** 標題逐字浮現（會把標題拆成大量 span，讀屏器與縮放都受影響）、磁吸按鈕、按鈕光環旋轉、捲動進度條、

## 12. 無障礙

- **對比：** §6.1 已逐組實算；鼠尾草與芥黃只做裝飾。所有主題與 hover／focus／selected／error 都要逐組驗。
- **鍵盤與焦點：** 沿用既有焦點管理；新的交錯列表維持 DOM 順序＝閱讀順序（視覺左右交錯不改 DOM）。
- **200% 放大與重排：** 文字全為 HTML（R-26），放大會跟著放大；320px 不得橫向捲動。
- **Reduced motion：** §10 每項都有關閉行為。
- **觸控目標：** 主要操作 44×44，其餘 ≥24×24（R-3）。
- **表單錯誤：** 保留錯誤摘要置頂、連到欄位、行內訊息一致。
- **讀屏器流程：** 地平線與弧線為 `aria-hidden` 裝飾；插圖給短 alt；比較表與鼻中隔五型的完整資訊都在頁面 HTML 上。
- **forced-colors：** 背景圖與裝飾 SVG 關閉，狀態不只靠背景色。

## 13. SEO

- 現況：`/clinic` 主要內容由 JS 產生，`<main>` 初始為空；全站 `noindex`；這是測試預覽的正確狀態，但**不適合正式上線**。
- 正式前必做：**建置時預先產生 HTML**（2026-08-11 現代化稽核 F-01 已建議），每條 `/clinic/**` 路由輸出完整內容與 metadata。
- 索引開關沿用 `WEB_PUBLIC_INDEXABLE` 與 `apps/web/public-pages.json`；正式網址仍待 D-011。
- **舊站 URL 轉址對照（新增必要項）：** 舊官網已有搜尋權重，換站時需 301，例如
  `/septoplasty/ → /clinic/nasal/septoplasty`、`/inferior-turbinate-surgery/ → /clinic/nasal/inferior-turbinate-surgery`、
  `/snoring-solution-five-in-one/`、`/snore-relief-sleep-mouthguard/`、`/doctors/`、`/reservations/ → /booking`。
  醫美頁的去向要等範圍決定（見 §16）。
- 結構化資料：沿用 `MedicalClinic` JSON-LD；療程頁補 `MedicalProcedure`；FAQ 頁的 `FAQPage` 只在內容經診所確認後加入。

## 14. 文案（你已同意可以重寫）

- **語氣：** 白話、先講結論與下一步；不催促、不承諾結果。
- **改寫原則：**
  - 不用「有效治療」「效果可改善 50% 以上」「根本解決」「一次解決」「完美」等保證療效的說法。

## 18. 最終判決

**我會批准「霧林呼吸」進入正式實作。**

- **為什麼是它：** 它是三個方向中唯一**完全由一森渼已付費素材構成**的方案；成本最低；
  兩個簽名（霧林地平線、呼吸弧線）都直接來自舊官網，病人一看就知道是同一間診所。
  它同時保留了現行版本做對的事：任務清楚、預約入口明確、可及性與效能閘門。
- **為什麼不是另外兩個：** Botanical 需要新畫一整套植物插畫，而且容易變成任何一家 wellness 品牌；
  診所實景深色路線只有 5 張照片可用，又很容易滑向醫美金黑模板，與鼻功能醫療的明亮可信不合。
- **什麼讓它一看就是一森渼：** 霧中的針葉林（名字裡的「森」）、鼻形標誌延伸出的呼吸弧線、
  舊官網那套白色醫學線稿，加上診所自己的候診區與古銅標誌牆照片——這些別家診所都沒有。

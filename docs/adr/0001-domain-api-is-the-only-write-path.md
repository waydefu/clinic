# ADR-0001：Domain API 是唯一業務寫入路徑

**狀態：** 已接受  
**日期：** 2026-07-20

## 決定

Web、社群、原生 App、管理後台與 NAS connector 一律透過 Domain API 執行預約、取消、到診、個管指派與薪資案件處理。客戶端不直接寫入 Firestore。

## 原因

預約防雙約、權限、個資遮罩、稽核、外部同步、計薪去重與月結鎖定必須在同一領域規則中執行。將規則放在前端或通路 webhook 會造成行為不一致且難以稽核。

## 後果

- 需要後端服務、服務帳號、監控與商用帳務。
- Firestore Rules 預設拒絕客戶端寫入；後端必須自行驗證 token、角色與欄位。
- 未來 App 可復用 API 契約而不必重寫預約規則。

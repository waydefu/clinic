# Web and UI

The normative interface rules are
[`docs/design/ui-ux-rules.md`](../../docs/design/ui-ux-rules.md) — R-1 to R-26
plus the mandatory acceptance matrix in §5. **Do not invent a second checklist.**
Run `/ui-check` to work that matrix.

## Boundaries

- The browser never touches Firestore directly and holds no business rule. It
  calls `apps/api` through the contract client (ADR-0001, ADR-0003).
- The test-only surfaces stay loopback-bound and synthetic-only. `check:ui`
  exists to stop that gating, the landmarks, the live-region updates and
  `:focus-visible` from being lost; if it fails, fix the UI, not the guard.
- The synthetic patient form collects only the fields the recorded owner batch
  approved. Adding a field is a privacy decision, not a UI decision.
- Compiled domain output under `apps/web/public/vendor/` is generated by
  `sync:domain` and verified by `check:sync`. Never hand-edit it.

## Gates that fail for non-obvious reasons

- **`check:tokens`** — the clinic site is inside the token scan. Raw colour,
  spacing and type values fail; use the scale.
- **`check:e2e-groups`** — every spec must belong to a group in
  [`scripts/e2e-groups.mjs`](../../scripts/e2e-groups.mjs). A new spec that is in
  no group silently never runs in CI, which looks exactly like passing.
- **`check:perf`** — the budget is a transitive closure from HTML, so **it only
  sees the reference forms it follows**. Images named in JS string constants were
  invisible until 2026-08-02, and `<meta property="og:image">` is still invisible
  today. Green here means "the tracked closure fits", not "the page was measured".
  Before changing a budget number, establish what the gate currently measures.
- **`check:structure`** — the visual baseline manifest pins each capture by
  sha256 and dimensions. Retake the baseline deliberately; do not edit hashes.

## Verification

Automated gates cannot see contrast in a real browser, a screen reader, a
physical device or a virtual keyboard. Items §5 covers but automation cannot
reach are reported as `External manual verification required` — never as passed.

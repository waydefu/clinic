# 一森渼診所線上預約
#
# 這份檔案只在預約系統**自己就是一個站台**時生效（現在的預覽頻道就是）。
# 等 /booking 併進 beauessence.com.tw 之後，robots.txt 由官網那一側擁有，
# 屆時要把下面的 Sitemap 行併進官網既有的 robots.txt，而不是蓋掉它。
#
# 預覽頻道刻意允許爬蟲檢索；HTTP `X-Robots-Tag: noindex` 是獨立於
# robots.txt 的 noindex 指示，爬蟲須能檢索到回應才能讀取標頭。Allow/Disallow
# 只規範爬蟲檢索路徑，不保證網址會保留或移出索引，也不是存取控制。

User-agent: *
Allow: /booking
Allow: /patient.html

# /index.html 的 Disallow 只規範爬蟲檢索，不等同 noindex，也不是存取控制；
# HTTP `X-Robots-Tag: noindex` 是獨立的索引指示。不能由 Disallow 推論
# /index.html 已自搜尋索引移除。
Disallow: /index.html

Sitemap: https://beauessence.com.tw/sitemap.xml
